十三、常用命令速查

# 进入博客根目录
cd /e/Blogfile

# 创建文章
npx hexo new "文章名称"

# 清除缓存
npx hexo clean

# 生成静态网站
npx hexo generate

# 启动本地服务器
npx hexo server

# 部署到GitHub
npx hexo deploy

# 一键发布
npm run publish

# 查看主题版本
npm list hexo-theme-redefine

# 检查Mermaid插件
npm list hexo-filter-mermaid-diagrams

# 检查MathJax插件
npm list hexo-filter-mathjax
